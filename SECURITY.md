# Сообщения об уязвимостях

Breeze — предварительная версия с временным root-помощником. Полного аудита безопасности не было; ограничения описаны в [docs/SAFETY.md](docs/SAFETY.md). Исправления безопасности планируются для текущей ветки `main`; гарантированного срока ответа нет.

Не публикуйте рабочие эксплойты и чувствительные данные в обычных issue. Используйте приватное сообщение об уязвимости через вкладку **Security → Advisories → Report a vulnerability** репозитория, если эта функция доступна. Если приватный канал недоступен, создайте issue только с просьбой предоставить приватный контакт, без технических деталей уязвимости.

Укажите версию/commit, модель и версию ОС без уникальных идентификаторов, предварительные условия, затронутую границу привилегий и безопасные шаги воспроизведения. Не прикладывайте пароли, токены, серийные номера и полные системные отчёты. Особенно интересны обходы валидации команд, подмена файлов сеанса и ошибки возврата к автоматическому управлению.
