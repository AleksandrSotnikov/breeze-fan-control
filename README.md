# Breeze

Плитка рабочего стола для наблюдения за температурой и управления вентиляторами Mac с Apple Silicon. Нативный интерфейс SwiftUI/AppKit размером 260 × 260, без сторонних библиотек и сетевых запросов.

**Статус: предварительная версия.** Чтение реальных датчиков и интерфейс проверены на MacBook Pro с M1 Pro. Ручная запись в SMC пока проверена только с подставным устройством в тестах. Готовая сборка имеет локальную ad-hoc подпись и не заверена Apple.

[Скачать предварительную сборку](https://github.com/AleksandrSotnikov/breeze-fan-control/releases) · [Установка и управление](docs/USER_GUIDE.md) · [Сборка](docs/DEVELOPMENT.md) · [Архитектура](docs/ARCHITECTURE.md) · [Устранение проблем](docs/TROUBLESHOOTING.md)

## Возможности

- Обороты двух вентиляторов, температура и график последних 45 измерений.
- Квадратная плитка под окнами приложений; положение сохраняется после перезапуска.
- Плавающий режим через меню «…» → «Поверх окон».
- Индивидуальная ручная скорость и возврат вентиляторов под управление macOS.
- Сеанс ручного управления до 15 минут с отдельным временным помощником.
- Контроль температуры, heartbeat и ошибок SMC с попыткой восстановления автоматического режима.

Это самостоятельное приложение с плиткой рабочего стола. Добавление через системную галерею виджетов macOS не поддерживается. Интерфейс приложения — на русском языке.

## Требования и проверенная совместимость

| Компонент | Требование / результат |
| --- | --- |
| Платформа | macOS 14+; исполняемые файлы arm64 |
| Проверенная модель | MacBookPro18,1, Apple M1 Pro, два вентилятора |
| Проверенная ОС | macOS 26.6.2 |
| Подтверждено на устройстве | Чтение оборотов, пределов, режимов, целевых оборотов и температуры; интерфейс и выход |
| Ручная запись на устройстве | Не проверена |
| Другие модели Apple Silicon | Не проверены; используются модельно-зависимые ключи SMC |
| Intel, Windows, Linux | Не поддерживаются текущей сборкой |
| Mac без вентилятора | Управлять нечем; приложение сообщает об отсутствии вентиляторов |

Минимальная версия macOS — цель сборки, а не результат проверки на каждой версии системы. Расширенные последовательности разблокировки SMC для других поколений Apple Silicon не реализованы.

## Быстрый запуск

1. Скачайте `Breeze-macOS-arm64.zip` и `SHA256SUMS.txt` из [релизов](https://github.com/AleksandrSotnikov/breeze-fan-control/releases).
2. Проверьте архив по инструкции в [руководстве](docs/USER_GUIDE.md#проверка-архива), распакуйте и переместите `Breeze.app` в «Программы».
3. Откройте приложение. Оно начинает с чтения показаний и не меняет охлаждение при запуске.
4. Кнопка с ползунками внизу плитки открывает управление. Для записи оборотов потребуется пароль администратора в системном окне macOS.

Локальная подпись не является Developer ID. macOS может заблокировать загруженный архив; порядок проверки и открытия описан в [руководстве](docs/USER_GUIDE.md#если-macos-блокирует-запуск).

## Сборка из исходников

Нужны Apple Command Line Tools со Swift 5.9 или новее и SDK macOS 14+. Полный Xcode и Swift Package Manager для сборки не требуются.

```sh
git clone https://github.com/AleksandrSotnikov/breeze-fan-control.git
cd breeze-fan-control
./build.sh
open Breeze.app
```

Скрипт собирает два исполняемых файла, подписывает приложение локально и запускает **40 проверок** без изменения реальных оборотов. На машине с arm64 они выполняются напрямую; на Intel полученная arm64-сборка не запускается. Подробности и упаковка — в [инструкции разработчика](docs/DEVELOPMENT.md).

Диагностика только для чтения, без прав администратора:

```sh
./Breeze.app/Contents/MacOS/Breeze --probe
```

## Ограничения ручного режима

| Условие | Действие |
| --- | --- |
| Запуск приложения | Только наблюдение |
| Допустимая скорость | От `max(1200, аппаратный минимум)` до аппаратного максимума |
| Срок ручного режима | До 900 секунд от последнего применения настроек |
| Температура от 90 °C / недопустимое показание | Прекращение ручного сеанса и попытка возврата к macOS |
| Heartbeat старше 8 секунд | Прекращение сеанса и попытка восстановления |
| Пауза между проходами помощника более 5 секунд | Прекращение сеанса после сна/паузы |
| Потеря телеметрии, изменение режима прошивкой, обычный выход | Попытка восстановления затронутых вентиляторов |

90 °C — консервативное правило Breeze, а не температурный предел Apple. При ошибках восстановления помощник повторяет попытки. SIGKILL самого помощника, аппаратная ошибка или отключение питания могут помешать восстановлению. См. [модель безопасности](docs/SAFETY.md) и [восстановление](docs/TROUBLESHOOTING.md#ручной-режим-не-сбрасывается).
