# Устранение проблем

[На главную](../README.md)

## Плитка не видна

По умолчанию плитка находится под обычными окнами. Покажите рабочий стол или нажмите значок вентилятора в строке меню: он переключает её видимость. В меню плитки «…» можно временно включить «Поверх окон».

При первом запуске ищите плитку слева вверху. При полностью недоступном сохранённом положении после смены мониторов приложение возвращает её на основной экран. Автозагрузка не настраивается автоматически: после перезагрузки Breeze нужно открыть заново, если пользователь не добавил его в объекты входа.

## macOS не открывает приложение

Предварительная сборка не имеет Developer ID и нотариализации. Проверьте источник и `SHA256SUMS.txt`; используйте штатный механизм разрешения macOS из [руководства](USER_GUIDE.md#если-macos-блокирует-запуск) либо соберите исходники. Не отключайте глобальные защиты системы.

## Нулевые обороты

В автоматическом режиме вентиляторы могут останавливаться. Breeze показывает фактическое значение SMC, а не выбранную скорость. Показания могут отличаться от другого приложения из-за момента опроса. Сам по себе ноль не подтверждает аппаратную неисправность.

## «Вентиляторы не обнаружены» / «Нет данных SMC»

Проверьте, есть ли физические вентиляторы и относится ли модель к проверенной совместимости. Выполните read-only диагностику:

```sh
./Breeze.app/Contents/MacOS/Breeze --probe
```

Запускайте из каталога сборки; для установленного приложения укажите его полный путь. Сохраните код ошибки и модель/версию ОС. На моделях с другими ключами или недоступным AppleSMC потребуется доработка. Приложение не подставляет вымышленные пределы, если чтение ключей вентилятора не удалось.

## Температура недоступна или неожиданна

Значение — максимум выбранных датчиков, а не усреднённая температура процессора. При отсутствии предпочтительных ключей используется запасной набор всех читаемых температурных ключей. Назначение ключей зависит от модели, а часть может быть недоступна. Сравнение с другим монитором имеет смысл только при одинаковых датчиках.

Если помощник не получает достаточно допустимых показаний, ручной сеанс прекращается. На очень горячей машине команда ручной скорости отклоняется начиная с 90 °C; этот порог — правило Breeze.

## Запрос прав отменён

Отмена системного запроса не применяет новую команду. Нажмите «Применить» заново, если всё же хотите изменить скорость. При обычном выходе во время незакрытого запроса авторизации приложение может ожидать его завершения; отмените запрос в системном окне.

## Не удалось записать `F0Md`, `F0Tg` или настройки не подтверждены

Причинами могут быть отказ авторизации, неподдерживаемая модель/прошивка, недоступный ключ или другой контроллер. Breeze прекращает сеанс и пытается вернуть затронутые вентиляторы в авто. Закройте другие контроллеры после возврата ими управления системе, дождитесь восстановления и проверьте read-only показания. Не пытайтесь обойти ограничение отключением SIP.

## «Другой сеанс Breeze уже управляет вентиляторами»

Уже работает привилегированный помощник, возможно он восстанавливает режим после сбоя. Верните управление через первоначально запущенное приложение или дождитесь завершения восстановления. Наличие пустого файла `/var/run/breeze.guardian.lock` само по себе не означает активную блокировку; при завершении процесса `flock` снимается системой.

## Ручной режим не сбрасывается

1. Откройте Breeze и выберите «Вернуть всё в авто»; подтвердите системный запрос при необходимости.
2. Если виден текст о восстановлении, дождитесь попыток помощника. Не завершайте сам помощник принудительно.
3. Проверьте режим через `--probe`, если чтение работает: Breeze трактует `mode == 1` как ручной режим. Любое другое значение само по себе не доказывает исправность охлаждения.
4. Если SMC продолжает отказывать и программный возврат невозможен, перезагрузите Mac и снова проверьте показания. При сохраняющейся аппаратной проблеме обратитесь к поддержке устройства.

## Ошибка сборки

Проверьте `xcrun swift --version`, активный SDK и наличие Command Line Tools. Скрипт требует zsh и собирает arm64. Ошибка выполнения тестов на Intel не означает поддержку этой архитектуры — она не реализована.

Ошибка `resource fork, Finder information, or similar detritus not allowed` связана с расширенными атрибутами пакета. Скрипт очищает их перед подписью; если облачная синхронизация возвращает метаданные, попробуйте чистый checkout в локальной несинхронизируемой папке и повторите сборку.

## Что приложить к issue

Используйте шаблон ошибки: версия Breeze, модель Mac без серийного номера, версия macOS, шаги воспроизведения, точная ошибка и при необходимости результат `--probe`. Укажите другие программы управления вентиляторами и характер операции: чтение, ручная скорость или возврат в авто. Не прикладывайте секреты и полные системные отчёты.
